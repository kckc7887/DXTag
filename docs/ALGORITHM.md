# DXTag 算法

DXTag 将一张 Simai 谱面映射为键盘、星星、技巧、体力、爆发五项分数。各项采用固定标尺归一化，输出范围为 0.0–10.0，保留一位小数。统一版本取自 `package.json` 的 `version`，当前为 `1.0.0`。

## 数据与计算入口

`listDifficulties(text)` 返回 maidata 中正文非空的 `inote_N` 编号。`scoreChart(text, slot)` 返回单谱结果，`scoreMaidata(text, selection?, onError?)` 返回按槽位升序排列的结果数组。选择参数接受正安全整数、编号数组或 `'all'`，缺省为全部。

结果结构为 `{title, slot, difficulty, scores}`。`slot` 保存原始编号；1–7 的显示名称依次为 EASY、BASIC、ADVANCED、EXPERT、MASTER、Re:MASTER、UTAGE，其他编号显示为 `inote_N`。完整接口见 [README](../README.md)。

| 数据 | 内容 |
| --- | --- |
| `Chart` | 曲名、作者、槽位、谱面元数据、音符、BPM、分度、速度及拍号事件 |
| `Note` | 类型、位置、起止拍点、起止时间、源码位置及音符属性 |
| `SlideBranch` | 路径段、等待时长、移动时长、时值声明 |
| `SlideEvent` | 分支身份、星头与移动时刻、路径长度、速度、转向和传感区区间 |
| `FiveAxisScores` | 键盘、星星、技巧、体力、爆发五项数值 |

```text
maidata → Simai 解析 → 音符与时间轴
                      ├─ 基础键盘与滑动负担
                      ├─ 星星运动、节奏、协调与上下文
                      ├─ 输入节奏与位移
                      └─ Touch 与 HOLD 占用
                           → 固定标尺 → 五轴融合 → 分数
```

## 解析与时间坐标

maidata 字段以行首的 `&名称=` 开始，字段名匹配忽略大小写，同名字段取最后一次声明。槽位字段为 `inote_N`，其中 `N` 为首位 1–9 的十进制正安全整数。正文去除首尾空白后有内容的槽位进入可选列表。

解析器读取 TAP、BREAK、HOLD、Touch、Touch HOLD、星形 TAP、Slide 分支及逐段连滑。音符保存原始源码行列、时值声明和位置。计分输入为 `isMine=false` 的音符，有头 Slide 的星头参与基础按键计数。

| 记法 | 数据含义 |
| --- | --- |
| `(BPM)` | BPM 事件 |
| `{n}` | 分度；逗号推进 `4/n` 拍 |
| `{#s}` | 逗号推进 `s` 秒 |
| `/` | 同拍音符组 |
| 反引号 | 相邻伪 EACH 组间隔 1 ms |
| `\|\|` | 行注释 |
| `<HS*>`、`<SV*>` | 速度元数据 |
| `\|\|s分子/分母` | 拍号元数据 |

`TimingTimeline` 按 BPM 事件分段积分，使用二分查找定位时间段。每段满足：

```text
Δt_ms = Δbeat × 60000 / BPM
```

解析结果包含四拍前置量，分析使用的谱面拍点和音频时间为：

```text
scoreBeat = chartBeat − 4
audioMs = chartMs − msFromBeat(4) + firstMs
```

结构节奏坐标扣除伪 EACH 的视觉偏移，实际运动时刻保留该偏移。`firstMs` 由 maidata 的 `first` 秒值换算。

Slide 的 `[a:b]` 时值为 `240000/BPM/a×b` 毫秒。指定 BPM 用于该段时值及默认一拍等待；`##` 左侧数值指定等待秒数。逐段连滑按各段时值累加，首段提供等待。末段统一声明时长时，各段按路径长度分配总时长。跨 BPM 的结束拍点由完整时间轴反算。

## 几何与分支关系

按钮圆半径为 `R=4.8`，第 `i` 个按钮的极角为 `π(5/8−i/4)`。Touch 的 A/D、B、E 半径分别为 4.1、2.2、3.1，C 位于圆心，D/E 相对 A/B 错开半个键位。

| 路径 | 几何结构 |
| --- | --- |
| `-` | 两点间的弦 |
| `v` | 经圆心的两段直线，支持返回起点 |
| `V` | 经指定按钮的两段弦 |
| `<`、`>`、`^` | 按钮圆上的有向圆弧，弧末端容差 0.001 rad |
| `p/q` | 半径 `R cos(3π/8)` 的中心圆与两端切线 |
| `pp/qq` | 半径 `R cos(π/8)/2` 的偏心圆与两端切线；绕行小于四分之一圈时增加一圈 |
| `s/z` | 三段折线，两个内部转折点互为对径点，半径 `R tan(π/8)` |
| `w` | 中心路径、相邻终点路径及扇形跨度 |
| `A/B/C/P/Q/K` | 通过公共切线连接点与圆的自定义路径 |

路径按 `Rπ/32` 的距离步长采样，保留终点，并在相邻样点之间线性插值。自定义路径的 `A/K` 表示按钮点，`B` 表示半径 `R tan(π/8)` 的内部点，`C` 表示圆心；`P/Q` 指定绕圆方向，0 表示中心圆，1–8 表示偏心圆。

传感区检测使用 A、B、C 圆域，圆心半径分别为 4.4、2.1、0，检测半径分别为 1.15、0.85、0.9。A/B 接触区间要求至少两个连续样点，区间按路径弧长比例转换为时间，终点区域记录到达事件。

基础负担中的同源 Slide 分组按较长路径优先建立两两相容的集合。参数为位置容差 `9.6×0.0025`、最大速度比 `1.01`、启动差与短路径时长之比 `1e-8`。比较点包含两条路径的折点与重叠区间端点。

星星复杂度按星头时刻、移动起止时刻、路径长度、扇形跨度和 32 段采样位置对完整轨迹去重。分支完整性检查使用音符 ID、分支序号、时值和几何长度；失败时公共接口抛出含分支数量和源码位置的错误。

## 基础负担

基础值 `KB、KS、KT、SB、SS、ST` 分别表示键盘与星星的爆发、体力、技巧。记谱面实际时长为 `D`，取首个音符至最后音符结束的秒数，最小值为 1。

### 键盘

记 `C_w` 为宽度 `w` 秒的按键计数窗口：

```text
KB = max(C_4)/4 + max(C_2)/2
KS = max(C_32)/32 + Q75(C_16)/16
```

2、4、16、32 秒窗口的步长分别为 0.5、1、4、8 秒。窗口区间为左闭右开。

```text
KT = 10/D × (
  纵连 + 大位移 + 2×交互 + 扫键 + 0.5×节奏变化 + 0.25×HOLD冲突
  + 3×长押手序 + 0.5×占手期间另一手负担 + 3×附点位移模式
  + 2×附点空间事件 + 1.5×双押换位 + 1.2×附点双押窗口
  + 双押扫键接Slide关系数
)
```

局部节奏单位取起音间隔的 15% 分位数，在四倍范围内尝试 1–4 分割，以整倍关系命中率至少 0.92 的分割为单位。附点关系使用 3:1、3:2、3:4 拍间隔比例和 2.5% 容差。纵连与交互的速率门槛为每秒 3 次。

### 滑动

`SB、SS、ST` 分别为滑动爆发、持续占用和技巧关系累积值乘 `10/D`。持续组使用动作数、忙碌覆盖率和忙碌秒数平方根的乘积。

技巧关系包括连滑转向、同头回击、等待期输入、HOLD 占用、启动接续、重复 TAP 接启动、路径接触、异速并行及双押扫键接 Slide。接触参数为提前接触 180 ms、最小领先 12 ms、采样间隔 35 ms。各关系的判定和累积位于 `src/algorithm/base-burden.ts` 及其导入的关系模块。

## 星星复杂度

单个动作包含运动 `M`、节奏 `R`、协调 `C`、上下文 `X`。去重动作数为 `N` 时：

```text
星星原值 = (ΣM + 0.7ΣR + 1.2ΣC + 1.5ΣX) / √N
星星技巧原值 = (0.15ΣM + 0.7ΣR + 1.2ΣC + 1.5ΣX) / √N
```

`N=0` 时两项取零。

### 运动与节奏

路径长度为 `L`、名义直径为 `d=9.6`、滑动时长为 `T` 秒，速度为 `v=L/(dT)`。32 段采样方向的相邻转角和除以 π 得曲率 `κ`，扇形跨度记为 `F`：

```text
M = (L/d) × (1+ln(1+v)) × (1+0.35κ+0.4F)
```

节奏项累加段速度变化、启动相位、附近启动间隔比、并发速度差和等待期节奏。段速度变化为对数速度相对持续时间加权均值的绝对偏差加权和，系数为 0.3。启动相位项为 `0.35×|sin(π×phase)|`，附近节奏项为相邻启动拍间隔绝对 `log2` 比值的均值。

### 并发协调

实际移动交叠的路径对在交叠区间内采样 8 次。两条路径时长为 `Ta、Tb`，交叠时长为 `O`：

```text
overlap = O / √(Ta×Tb)
independence = mean(位置距离/d + 0.35×方向夹角/π)
speedDifference = |log2(va/vb)|
pairCost = overlap × (
  0.2 + independence + 0.2×speedDifference
  + 0.2×|启动时间差|/√(Ta×Tb)
)
```

`pairCost` 各半计入两条路径的协调项。两条路径的节奏项各增加 `0.15×overlap×speedDifference`。

### 上下文与等待

上下文覆盖星头前 2 拍至滑尾后 2 拍的外来输入，以及更早开始并覆盖该区间的 HOLD。

记空间接近度为 `p=exp(-3×距离/d)`、HOLD 交叠占星头至滑尾时长的比例为 `h`、边界位移除以直径为 `b`。动作外的拍间隔除以等待拍跨度得 `g`，零等待时使用移动拍跨度；动作内 `g=0`。边界压力 `q=1+0.8/(1+边界毫秒间隔/滑动时长)`，动作内取 1。

```text
coupling = (0.18+0.7p+0.55h+0.65b) × q / (1+g²)
waitingBase = ln(1+等待期输入数) × ln(1+等待期起音频率)
X = ln(1+Σcoupling) + 0.5×waitingBase + 跟随负担 + 回占负担
R += 0.5×waitingBase×等待节奏不规则度
```

等待输入按音符 ID 去重，起音频率为结构起音组数除以等待区间并集秒数。等待节奏包含星头、等待期输入和启动拍。

### 跟随与回占

```text
跟随负担 = ln(1+T) × √(1+L/d)
affinity = max(0, 1−(输入到原星头距离/r0)²)
returnCost = 3×affinity×路径到输入位置距离/d
             ×(1+ln(1+剩余滑动秒数))×(1+ln(1+HOLD交叠秒数))
回占负担 = ΣreturnCost
```

`r0` 为原按钮到相邻按钮距离的一半。回占使用有头 Slide 在移动期间原星头附近的外来输入。TAP 的 HOLD 交叠秒数为零，HOLD 按实际交叠区间采样路径距离。

### 局部窗口与爆发

局部窗口宽 16 拍、步长 4 拍，窗口上下文各延伸 2 拍。每个动作按星头至滑尾区间与窗口的交叠比例分配权重，各分量加权后除以权重和的平方根。

爆发采用宽 4 拍、步长 4 拍的序列，空块取零，首块前值为零：

```text
星星爆发原值 = max_i(max(0, s[i]−s[i−1]))
```

## 输入节奏与位移

输入起音由 TAP、BREAK、HOLD 起点、Touch、Touch HOLD 起点和星形 TAP 组成，同拍输入合并。

设相邻起音拍间隔为 `IOI`，对 `log2(IOI)` 中心化，取标准差 `σ`，相邻绝对对数比均值为 `A`：

```text
A = mean(|log2(IOI[i+1]/IOI[i])|)
节奏不规则度 = σ + 0.5A + 0.5A×(1−adaptation)
```

至少四个间隔时，搜索 1–4 个间隔组成的周期，并要求至少两个完整周期。周期目标为平均误差加 `0.25×(周期−1)/间隔数`。

```text
adaptation = (间隔数−周期) / 间隔数 / (1+平均周期误差)
```

起音窗口最多包含 17 组，相邻窗口共享一个边界起音。相邻间隔的恢复权重和执行节奏值为：

```text
w[i] = 2×min(IOI[i], IOI[i+1]) / (IOI[i]+IOI[i+1])
E = mean(|log2(IOI[i+1]/IOI[i])|×w[i]) × (1+0.5×(1−adaptation))
windowRaw = E × 实际起音频率 × (1+平均位移/4)
```

按钮间位移取最短环形键数距离；Touch 或混合输入取传感区距离除以 2.4，最大值为 4。双押组间位移取双向最近位置距离均值的平均数。

全谱输入节奏原值为按 IOI 数加权的窗口均值与加权 90% 分位值各占一半。

## Touch 与 HOLD 占用

Touch 计一次输入，Touch HOLD 计一个起点及占用区间：

```text
touchRaw = √Touch输入数 × (1+ln(1+实际Touch起音频率)) × (1+平均位移/4)
```

实际 Touch 起音频率为相邻起音组数量除以首尾起音秒数；单组起音时取零。

HOLD 在 `[开始,结束)` 区间收集外来输入。锁手项处理 Touch HOLD，以及含 Touch 输入的普通 HOLD。设占用时长为 `t` 秒、平均起音间隔为 `i` 秒、外来音符数为 `n`、实际起音率为 `r`：

```text
sustained = ln(1+t) × ln(1+n) × ln(1+r) × t/(t+i)
movement = sustained × 平均位移/4
coordination = sustained × mean(其他HOLD压力之和)
lockWindowRaw = sustained + movement + coordination
lockRaw = ΣlockWindowRaw / √有效窗口数
```

其他 HOLD 的压力为 `d/(1+d) × u/(u+i)`，`d` 为两个 HOLD 的位置距离，`u` 为另一 HOLD 的时长。单组输入时 `i=t`，有效窗口数为零时 `lockRaw=0`。

## 固定标尺与五轴输出

标尺数据位于 `src/scale.json`，样本为按 Simai 指纹去重的 7011 张有效普通谱，冻结日期为 2026-10-01。

```text
anchor = max(全部有效谱 P99.5, 非零有效谱 P99)
normalized = clamp(raw/anchor × 100, 0, 100)
```

| 项目 | 锚点 |
| --- | ---: |
| 基础键盘 | 100.07579192161403 |
| 基础星星 | 96.01729591685351 |
| 基础技巧 | 62.42835191293171 |
| 基础体力 | 23.02031527874421 |
| 基础爆发 | 55.952189168537394 |
| 星星复杂度 | 129.2398804700811 |
| 星星技巧 | 84.61633871295246 |
| 星星突增 | 36.053922198520475 |
| 输入节奏 | 4.831614877974868 |
| Touch 输入 | 26.809017831959324 |
| HOLD 锁手 | 13.057057014833532 |

基础量 `KB+KS+KT`、`KT+ST`、`KS+SS`、`KB+SB` 归一化为 `K0、T0、S0、B0`，取最近整数，恰好半整数时取偶数。星星、节奏与占用支持量在 0–100 区间保留一位小数。

设 `Xs、Xt、Xb、R、H、L` 分别表示归一化后的星星复杂度、星星技巧、星星突增、输入节奏、Touch 输入和锁手：

```text
键盘 = 100 − (100−K0) × (1−0.65H/100) × (1−0.35L/100)
星星 = Xs
技巧 = 100 − (100−T0) × (1−0.65Xt/100) × (1−0.65R/100) × (1−0.65L/100)
体力 = S0
爆发 = 100 − (100−B0) × (1−0.65Xb/100)
```

融合量在 0–100 区间保留一位小数，公共分数按下式转换：

```text
scores[axis] = Math.round(internalScore[axis]) / 10
```
