# 五维评分实现

## 1. 数据与接口

每张谱面的结果包含 `title`、`difficulty`、`scores`、`chartRelativeScores`。`title` 取自 maidata 的 `&title`，`difficulty` 由选中的普通谱槽位确定。

`scores` 使用全曲库固定标尺，可跨谱面比较；`chartRelativeScores` 将同一谱面的最高维度换算为 10.0，用于比较该谱面内部的五维强弱。两组数值均为 0.0–10.0：

| 轴 | 计算内容 |
| --- | --- |
| 键盘 | 按键密度、手序、Touch 输入及占手负担 |
| 星星 | Slide 运动、启动节奏、并发协调、跟随和接续复杂度 |
| 技巧 | 手序、不规则节奏、星星协调及锁手负担 |
| 体力 | 持续键盘密度与连续滑动占用 |
| 爆发 | 短时输入负担及局部星星复杂度突增 |

`scoreChart(text, difficulty)` 返回一个结果对象。`scoreMaidata(text, difficulty?, onError?)` 返回结果数组；省略难度时计算 `inote_2` 至 `inote_6` 中存在的谱面。计算错误默认抛出异常；提供 `onError` 时，回调接收 `{difficulty, message}`，随后继续处理其他谱面。

CLI 将结果数组写入标准输出，错误写入标准错误。JSON 数值固定显示一位小数。

## 2. 计算流程

```text
maidata → SimaiParser → 音符、BPM／分度事件、时值、源码位置
                        ├─ TimingTimeline：拍点与实际时间
                        ├─ baseBurden：基础负担与 Slide 事件
                        ├─ starComplexity：星星复杂度
                        ├─ keyboardRhythmComplexity：节奏与位移
                        └─ inputComplexity：Touch 与锁手
                             → 固定标尺 → 五轴融合 ┬→ scores（全曲库）
                                                   └→ chartRelativeScores（谱面自身）
```

| 文件 | 职责 |
| --- | --- |
| `src/index.ts` | 公共接口、完整性检查、归一化与结果组装 |
| `src/cli.ts` | 参数、文件解码、JSON 与退出码 |
| `src/simai/core/parser/SimaiParser.ts` | maidata 字段与谱面时钟 |
| `src/simai/core/parser/lexical.ts` | 词法读取、数值检查与源码定位 |
| `src/simai/core/parser/duration.ts` | 等待与移动时值解算 |
| `src/simai/core/parser/notes.ts` | 音符、分支与逐段连滑构造 |
| `src/simai/core/timing/TimingTimeline.ts` | BPM 积分和时间转换 |
| `src/simai/core/geometry/` | 路径、判定区与 Touch 坐标 |
| `src/algorithm/base-burden.ts` | 六项基础负担 |
| `src/algorithm/analysis-*.ts` | 启动、接续、扫键等局部关系 |
| `src/algorithm/star-complexity.ts` | 星星运动、节奏、协调和上下文 |
| `src/algorithm/rhythm-complexity.ts` | 起音间隔与位移 |
| `src/algorithm/input-complexity.ts` | Touch 输入和锁手 |

## 3. 时间轴与 Slide 事件

`TimingTimeline` 按 BPM 事件分段积分，通过二分查找实现拍点与毫秒互转：

```text
Δt_ms = Δbeat × 60000 / BPM
```

分析坐标扣除解析器的四拍前置量，并统一处理 `first` 偏移。节奏比例、启动相位和前后两拍上下文使用谱面拍坐标；路径速度、重叠、HOLD 占用和恢复使用实际时间。

解析器保存原始时值、声明 BPM、指定 BPM、秒数等待和逐段连滑时长。`[a:b]` 根据声明 BPM 换算，`##` 指定等待；连滑逐段累加，首段确定启动。跨 BPM 的终点拍坐标由完整时间轴反算。

同头分支分别建模，支持折返、扇形、无头、伪 EACH 及已实现的秒数兼容写法。星形 TAP 归入敲击；无真实 Slide 时星星分数为零。地雷从评分输入中排除。

每条分支按 `音符 ID:分支序号` 核对来源、星头、启动、终点、逐段时长和几何长度。完整性检查失败时抛出包含分支数、源码行与路径的错误。

### 3.1 语法读取

按 [Simai 谱面书式](https://w.atwiki.jp/simai/pages/1002.html) 读取音符与时间声明。词法层跳过空白与 `||` 行注释，同时保留每个有效字符在原文件中的位置。逗号按当前分度推进时间；`/` 形成同拍组，反引号形成相差 1 ms 的伪 EACH。解析结果保存源码行、列和原始片段。

`[a:b]` 的移动时长为 `240000/BPM/a×b` 毫秒。指定 BPM 改变该时值及默认一拍等待；`##` 的左侧显式指定等待秒数。逐段连滑每段单独换算实际时长，只由首段确定等待。仅在末段声明时长的连滑按路径长度分配移动时间。

`{#秒数}` 固定逗号的实际间隔；变速后按新 BPM 重新计算对应拍跨度。`<HS*>`、`<SV*>` 和 `||s分子/分母` 保存为速度／拍号元数据。`1v1` 支持经过中心后返回起点；自定义 `A/B/C/P/Q/K` 路径作为扩展记法解析。

### 3.2 路径几何

`curves.ts` 提供直线、圆弧、切线和按弧长定位；`slidePath.ts` 根据起点、终点与路径类型组合这些曲线。按钮圆半径 `R=4.8`，第 `i` 个按钮的极角为 `π(5/8−i/4)`。

- `-`：两端之间的弦；`v`：两条经过圆心的线段；`V`：经过指定按钮的两条弦。
- `<`、`>`、`^`：按钮圆上的有向圆弧。弧末端保留 0.001 rad 的数值容差。
- `p/q`：对半径 `R cos(3π/8)` 的中心圆作进入、绕行及离开的切线连接。
- `pp/qq`：使用半径 `R cos(π/8)/2` 的偏心圆，中心距圆心也为此半径；绕行不足四分之一圈时延伸一整圈。
- `s/z`：三条线段组成的折线，两个内部转折点互为对径点，距圆心 `R tan(π/8)`。
- `w`：中心直线与相邻终点的两条侧线共同提供扇形跨度和接触关系。

曲线按 `Rπ/32` 的距离步长采样，补上终点，查询时在相邻样点间线性插值。完整路径的长度决定整体连滑的时长分配；逐段指定时长时直接使用各段时值。生成结果在本次进程内缓存。

`custom.ts` 通过公共切线连接点与圆：`A/K` 是按钮点，`B` 是半径 `R tan(π/8)` 上的内部点，`C` 是中心；`P/Q` 指定绕圆方向，索引 0 为中心圆，1–8 为八个偏心圆。重复的同一绕圆节点增加一整圈。

### 3.3 传感区接触

Touch 坐标使用 A/D、B、E 三组半径 4.1、2.2、3.1，C1/C2 合并到圆心。D/E 的角度相对 A/B 错开半个键位。

路径接触采用空间近似：A、B、C 的检测圆心半径分别为 4.4、2.1、0，检测半径分别为 1.15、0.85、0.9。`sensors.ts` 找到路径连续落入这些区域的样点区间，区间通过已计算的弧长比例转换到实际时间。A/B 保留至少两个连续样点的接触；终点区域记为到达事件。扇形另计两条侧线与邻近 D 区的到达覆盖。

这些区间用于基础技巧中的路径冲突估计。星星连续复杂度直接使用轨迹、速度、节奏和前后输入关系。

## 4. 基础负担

六项基础值记为 `KB, KS, KT, SB, SS, ST`，分别对应键盘／星星的爆发、体力、技巧。

设 `C_w` 为宽度 `w` 秒的按键计数窗口：

```text
KB = max(C_4)/4 + max(C_2)/2
KS = max(C_32)/32 + Q75(C_16)/16
```

2、4、16、32 秒窗口的滑动步长依次为 0.5、1、4、8 秒。按键集合包括有头 Slide 的星头。Touch 使用第 7 节的输入补充。

键盘技巧使用以下计数：

```text
KT = 10/D × (
  纵连 + 大位移 + 2×交互 + 扫键 + 0.5×节奏变化 + 0.25×HOLD冲突
  + 3×长押手序 + 0.5×占手期间另一手负担 + 3×附点位移模式
  + 2×附点空间事件 + 1.5×双押换位 + 1.2×附点双押窗口
  + 双押扫键接Slide关系数
)
```

`D` 为首个音符到最后结束音符的实际秒数，最小取 1。各计数器及其条件位于 `base-burden.ts`。

`SB, SS, ST` 将滑动爆发、持续占用和技巧关系的累积值乘 `10/D`。持续组按“动作数 × 忙碌覆盖率 × 忙碌秒数平方根”计量；技巧关系包含连滑转向、同头回击、启动接续、路径接触、不同速并行及双押扫键接 Slide。

这些基础值进入键盘、技巧、体力与爆发轴。星星轴使用下一节的连续复杂度。

## 5. 星星复杂度

每条完整、带时间的路径构成一个动作。星头时间、移动时间、长度、扇形跨度与采样位置完全重合的轨迹去重，分岔和不同时间的轨迹分别计算。

每个动作产生运动 `M`、节奏 `R`、并发协调 `C`、上下文 `X`。设唯一动作数为 `N`：

```text
星星原值 = (ΣM + 0.7ΣR + 1.2ΣC + 1.5ΣX) / √N
星星技巧原值 = (0.15ΣM + 0.7ΣR + 1.2ΣC + 1.5ΣX) / √N
```

`N=0` 时取零。

### 5.1 运动

设路径长度为 `L`，圆盘名义直径 `d=9.6`，滑动时长为 `T` 秒，`v=L/(dT)`。路径分为 32 段采样，相邻方向转角和除以 π 得曲率 `κ`；扇形末端跨度记为 `F`：

```text
M = (L/d) × (1+ln(1+v)) × (1+0.35κ+0.4F)
```

连滑转向计入采样方向变化，扇形计入中心线路径与末端跨度。

### 5.2 节奏

`R` 累加以下量：

- 各段对数速度相对持续时间加权均值的偏差，权重 0.3。
- 星头到启动相位相对附近启动间隔的偏移：`0.35×|sin(π×phase)|`。
- 附近相邻启动拍间隔的绝对 `log2` 比例变化。
- 并发路径速度差，以及等待期间的不规则节奏。

### 5.3 并发协调

区间扫描枚举实际移动有交叠的路径对。每个交叠区间采样 8 次，取位置距离、方向夹角、速度差与启动时间差。

设路径时长为 `Ta,Tb`，交叠时长为 `O`：

```text
overlap = O / √(Ta×Tb)
independence = mean(位置距离/d + 0.35×方向夹角/π)
speedDifference = |log2(va/vb)|
pairCost = overlap × (0.2+independence+0.2×speedDifference
                      +0.2×|启动时间差|/√(Ta×Tb))
```

`pairCost` 各半计入两条路径的 `C`。两条路径的 `R` 各增加 `0.15×overlap×speedDifference`。

### 5.4 接续与等待

上下文从星头前 2 拍延伸至滑尾后 2 拍，包含外来 TAP、BREAK、HOLD、Touch、Touch HOLD 及有头 Slide。更早开始且仍覆盖该动作的 HOLD 同样参与。

设空间接近度 `p=exp(-3×距离/d)`，HOLD 重叠比例为 `h`，边界移动距离除以直径为 `b`；动作外的拍间隔除以自身等待跨度为 `g`，零等待时使用移动跨度。边界压力 `q=1+0.8/(1+边界毫秒间隔/滑动时长)`，动作内取 1：

```text
coupling = (0.18+0.7p+0.55h+0.65b) × q / (1+g²)
X = ln(1+Σcoupling) + 等待负担 + 跟随负担 + 回占负担
```

等待期统计真实输入数 `n` 和实际起音频率 `r`，同头分支按音符 ID 去重：

```text
waitingBase = ln(1+n) × ln(1+r)
等待负担 = 0.5×waitingBase
R += 0.5×waitingBase×等待拍间隔不规则度
```

等待节奏同时包含星头、期间输入和启动拍，因此附点及长短交错会增加不规则度。

### 5.5 慢速跟随与原星头回占

跟随负担采用实际滑动时长：

```text
跟随负担 = ln(1+T) × √(1+L/d)
```

回占检查滑动期间原星头附近的外来输入。邻域半径 `r0` 为原按钮到相邻按钮距离的一半：

```text
affinity = max(0, 1-(输入到原星头距离/r0)²)
returnCost = 3×affinity×路径到输入位置距离/d
             ×(1+ln(1+剩余滑动秒数))×(1+ln(1+HOLD重叠秒数))
回占负担 = ΣreturnCost
```

TAP 的 HOLD 重叠秒数为零。长押按实际交叠区间采样路径距离；附近 Touch 使用真实坐标。检查范围排除自身星头、精确启动拍与滑尾；无头 Slide 的回占负担为零。

### 5.6 突增

以四拍为统计网格，按动作星头至终点与分块的交叠比例分配权重。上下文裁切到分块前后两拍，恢复块保留零值。设每块复杂度为 `s[i]`：

```text
星星爆发原值 = max_i(max(0, s[i]-s[i-1]))
```

## 6. 输入节奏与位移

TAP、BREAK、HOLD 起点、Touch、Touch HOLD 起点和星形 TAP 组成输入起音组。同拍合并，伪 EACH 的视觉偏移在结构坐标中扣除。

相邻起音拍间隔记为 IOI。对 `log2(IOI)` 减去均值后，计算标准差、相邻比例差，并搜索 1–4 个间隔的重复周期：

```text
A = mean(|log2(IOI[i+1]/IOI[i])|)
节奏不规则度 = log2间隔标准差 + 0.5A + 0.5A×(1-重复适应度)
```

周期选择使用平均周期误差和 `0.25×(周期-1)/间隔数` 的惩罚项。重复适应度为 `(间隔数-周期)/间隔数/(1+周期误差)`；间隔少于 4 时取零。

键盘窗口包含最多 17 个起音组，相邻窗口共享一个边界起音。用连续恢复权重衰减长休息附近的节奏对比：

```text
w = 2×min(IOI[i],IOI[i+1]) / (IOI[i]+IOI[i+1])
E = mean(相邻对数比例差×w) × (1+0.5×(1-重复适应度))
windowRaw = E × 实际起音频率 × (1+平均位移/4)
```

全谱取按间隔数加权的均值与 90% 分位窗口值，各占一半。

按钮位移使用最短环形键数距离；涉及 Touch 时使用传感区距离除以 2.4，上限为 4。双押组间位移取双向最近位置距离的均值。

## 7. Touch 与锁手

Touch 计一次输入，Touch HOLD 计一个起点和实际占用区间。Touch 输入原值为：

```text
touchRaw = √Touch输入数 × (1+ln(1+实际Touch起音频率)) × (1+平均位移/4)
```

锁手在 HOLD 的 `[开始,结束)` 内收集其他输入。该补充分量处理 Touch HOLD，以及包含 Touch 的普通 HOLD 区间。

设占用时长为 `t` 秒，平均起音间隔为 `i`，外来音符数为 `n`，实际起音率为 `r`：

```text
sustained = ln(1+t) × ln(1+n) × ln(1+r) × t/(t+i)
movement = sustained × 平均位移/4
coordination = sustained × 平均其他HOLD占用压力
lockWindowRaw = sustained + movement + coordination
lockRaw = ΣlockWindowRaw / √有效窗口数
```

其他 HOLD 的压力按 `d/(1+d) × u/(u+i)` 计算，`d` 为两个 HOLD 的位置距离，`u` 为其他 HOLD 的长度。短 HOLD 通过占用比例连续衰减。没有外来输入的 HOLD，其锁手负担为零。

## 8. 归一化与融合

各观察量使用全库有效普通谱按 Simai 指纹去重后冻结的锚点：

```text
anchor = max(全部有效谱 P99.5, 非零有效谱 P99)
normalized = clamp(raw/anchor × 100, 0, 100)
```

固定锚点位于 `src/scale.json`：

| 观察量 | 锚点 |
| --- | ---: |
| 基础键盘 | 100.07579192161403 |
| 基础技巧 | 62.42835191293171 |
| 基础体力 | 23.02031527874421 |
| 基础爆发 | 55.952189168537394 |
| 星星复杂度 | 129.2398804700811 |
| 星星技巧 | 84.61633871295246 |
| 星星突增 | 36.053922198520475 |
| 输入节奏 | 4.831614877974868 |
| Touch 输入 | 26.809017831959324 |
| Touch 锁手 | 13.057057014833532 |

将 `KB+KS+KT`、`KT+ST`、`KS+SS`、`KB+SB` 归一化后记为 `K0,T0,S0,B0`，取最近整数，恰好半整数时取偶数。新支持项在 0–100 上保留一位小数。

设 `Xs,Xt,Xb,R,H,L` 分别为归一化的星星复杂度、星星技巧、星星突增、输入节奏、Touch 输入和锁手：

```text
键盘 = 100 - (100-K0) × (1-0.65H/100) × (1-0.35L/100)
星星 = Xs
技巧 = 100 - (100-T0) × (1-0.65Xt/100) × (1-0.65R/100) × (1-0.65L/100)
体力 = S0
爆发 = 100 - (100-B0) × (1-0.65Xb/100)
```

融合值在 0–100 上保留一位小数，再转为全曲库公共分数：

```text
scores[axis] = Math.round(internalScore[axis]) / 10
maxAxis = max(internalScore[键盘], internalScore[星星], internalScore[技巧], internalScore[体力], internalScore[爆发])
chartRelativeScores[axis] = maxAxis > 0 ? Math.round(internalScore[axis] / maxAxis × 100) / 10 : 0
```

`chartRelativeScores` 在 `scores` 的显示舍入前计算，因此低分维度不会因提前舍入丢失；五维全为零时返回五个零。每张谱面独立计算，相对值不可跨谱面比较。

## 9. 构建与测试

```powershell
npm run build
npm test
```

构建先执行 TypeScript 类型检查，再由 esbuild 生成 `dist/cli.mjs` 和 `dist/index.mjs`。

测试覆盖输出字段、难度选择、编码、退出码、节奏与位移、等待附点、前后接续、并发 Slide、慢速跟随、原星头回占、跨 BPM、Touch HOLD 与短 HOLD 边界。真实谱测试核对《enchanted love》的节奏证据和《TECHNOPOLIS 2085》的锁手区间。

底层测试另覆盖逐段连滑、指定 BPM／秒数、源文本位置、修饰符、560 种常规端点组合、V 折返及自定义点／圆连接。`real_chart_regression.test.ts` 固定 12 张真实谱的五维结果。

真实谱测试从 `DXTAG_CHARTS_DIR` 指定的谱面库中读取 `版本目录/曲名/maidata.txt`，环境变量未设置或对应文件缺失时标记跳过：

```powershell
$env:DXTAG_CHARTS_DIR = '.\charts'
npm test
```
